GD ULTIMATE MENU — ANDROID CLOUD BUILD PROJECT v0.1.0
Geometry Dash Android 2.2081 / Geode

ЭТО ИСХОДНИКИ, А НЕ ГОТОВЫЙ .geode.
Внутри проекта есть GitHub Actions workflow, который собирает мод в облаке для
Android32 и Android64, затем объединяет платформы в один .geode-файл.

ЧТО ЕСТЬ В ЭТОЙ ЗАГОТОВКЕ
- кнопка в нижнем меню Geometry Dash;
- окно GD Ultimate Menu;
- настройки скорости, низкой гравитации и визуальных эффектов.

ВАЖНО: в текущем starter-коде настройки только сохраняются и показываются.
Они пока НЕ изменяют скорость, гравитацию или эффекты в самой игре.
Сборка не проверена запуском на устройстве. Используй её как тестовую заготовку.

СБОРКА С ТЕЛЕФОНА ЧЕРЕЗ GITHUB
1. Распакуй этот ZIP на телефоне.
2. Создай новый репозиторий на GitHub и загрузи туда все файлы проекта,
   включая скрытую папку .github (в ней находится workflow).
3. Открой вкладку Actions в репозитории.
4. Выбери "Build GD Ultimate Menu for Android" и нажми "Run workflow".
   Также сборка запускается автоматически после push.
5. Дождись зелёного статуса завершения.
6. Открой завершённый запуск workflow и скачай artifact
   "GD-Ultimate-Menu-Android". Внутри будет файл .geode.
7. Скопируй .geode в папку Geode mods:
   Android/media/com.geode.launcher/game/geode/mods/
   (точный путь может отличаться у другой сборки/версии лаунчера).
8. Перезапусти Geometry Dash и включи мод в Geode.

Если workflow завершился ошибкой, открой лог конкретного шага сборки.
Ошибка может быть связана с несовместимостью исходников и актуального SDK.

Официальный builder, который используется workflow:
https://github.com/geode-sdk/build-geode-mod
